## 🌟 Características Principais

- **13 Universos Dimensionais Únicos:** Cada dimensão possui sua própria atmosfera, iluminação dinâmica, clima com partículas, paleta de cores, música e cenários parallax de 4 camadas.
- **156 Fases Exclusivas:** 12 fases temáticas em cada universo, com progressão equilibrada de dificuldade e mecânicas próprias.
- **Modo Speedrun com Rank S / A / B / C:** Cronômetro de precisão, metas calibradas e gravação de Personal Best (PB) persistente.
- **História & Lore de Nix:** Acompanhe a recuperação do gatinho Nix a cada fase concluída com status de saúde e diálogos temáticos.
- **Mecânicas Avançadas:**
  - ⚡ **Hiper Dash:** Arrancada com invulnerabilidade temporária.
  - 🚀 **Boost Pads:** Impulso de aceleração supersônica.
  - 🍄 **Cogumelos & Molas:** Saltos verticais de grande altitude.
  - 💨 **Correntes de Vento:** Updrafts e flutuação suave.
  - 🧊 **Plataformas de Gelo & Móveis:** Superfícies escorregadias e elevadores móveis.
  - 💥 **Paredes Destrutíveis:** Atalhos secretos e cristais ocultos.
  - 🛡️ **Power-ups Coletáveis:** Escudo de Aurora, Ímã Astral, Ampulheta Temporal, Asas Celestiais e Coração Estelar.
- **Guarda-Roupa Dimensional Interativo:** Alterne em tempo real entre os 13 trajes no menu principal com pré-visualização de retrato de alta resolução e animações 2D.
- **Controles Universais:**
  - Teclado: Setas / WASD para mover, `Espaço` / `Z` para pular, `Shift` / `X` para correr, `C` / `J` para Dash.
  - Mobile: Botões touch responsivos com configurações de escala, opacidade e modos de corrida na tela.

## 🏗️ Como Executar Localmente

### Pré-requisitos
- [Godot Engine 4.7+](https://godotengine.org/download)

### Execução
1. Clone este repositório:
   ```bash
   git clone https://github.com/evolucaomente27-bot/Linaverse-plataform-game.git
   ```
2. Abra o Godot Engine e importe o arquivo `project.godot`.
3. Pressione `F5` para iniciar o jogo ou execute via linha de comando:
   ```bash
   godot --path .
   ```
